# Полиглот

Веб-приложение для изучения иностранных языков (английский, испанский, немецкий, французский). Без сборки и зависимостей — откройте `index.html` в браузере.

- **Карточки** с интервальным повторением (метод Лейтнера, 6 ящиков)
- **Тест** с вариантами ответа и **письменные упражнения**
- Озвучка через Web Speech API
- Свои слова, прогресс по темам, XP и серия дней (хранятся в localStorage)

Новый язык: добавьте запись в `LANGUAGES` в `data.js`.

## Установка на телефон (PWA)

Приложение работает как PWA: устанавливается на главный экран и открывается офлайн.

1. Опубликуйте репозиторий на GitHub Pages: *Settings → Pages → Deploy from a branch*, выберите ветку и папку `/ (root)`.
2. Откройте выданную ссылку на телефоне: в Chrome нажмите «Установить приложение» / «Добавить на главный экран», в Safari — «Поделиться → На экран „Домой“».
3. Ссылкой можно поделиться с друзьями, в приложении есть кнопка 📤.

Локально: `python3 -m http.server` и откройте `http://localhost:8000`.
